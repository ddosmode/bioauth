# AGENTS: Модуль src/

## 1. ЦЕЛЬ
Реализовать ядро системы:
- `capture.py`: Быстрый прогрев и захват 1-3 кадров с V4L2/OpenCV устройства (`/dev/video0`). Освобождение камеры через `try...finally`.
- `detector.py`: Детекция лица через `cv2.FaceDetectorYN`.
- `recognizer.py`: Извлечение вектора через `cv2.FaceRecognizerSF` и вычисление косинусного сходства (Cosine Similarity). Порог совпадения: 0.363 (L2) или 0.40 (Cosine).
- `cli.py`: Консольный интерфейс `bioauth` (команды: `enroll`, `verify`, `test`).

## 2. ЧТО СДЕЛАТЬ
- Обеспечить чистую модульную структуру без глобальных блокировок.
- Обработку случаев: камера занята другим процессом, лицо не обнаружено, найдено более одного лица.
- Вывод понятных статусов и кодов возврата (0 при успехе, 1 при несовпадении, 2 при ошибке устройства/камеры).

## 3. ГРАНИЦЫ
- Не модифицировать файлы в `pam/` и `/etc/pam.d/`.
- Не использовать сторонние тяжёлые зависимости (`torch`, `dlib`, `tensorflow`). Только `cv2` и `numpy`.

## 4. ПРОВЕРКА
- Запуск `python3 -m bioauth.cli --help` и `python3 -m bioauth.cli verify`.
- Проверка скорости выполнения: верификация должна укладываться в < 1 секунды.

## 5. РЕЗУЛЬТАТ
Работоспособный CLI и импортируемые модули захвата и верификации.
