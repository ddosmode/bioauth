# Проект: bioauth (Biometric Face Authentication for Linux)

## Общие правила проекта
Система биометрической аутентификации лица для PAM (`sudo`, экран блокировки GNOME/GDM) на базе OpenCV YuNet и SFace.
Система написана по стандартам Linux-разработки: модульная архитектура, строгая обработка исключений, мгновенный выход (fail-fast), нулевые утечки ресурсов камеры.

## Стек и архитектура
- Язык: Python 3.12+ (стандартная библиотека + OpenCV с поддержкой FaceDetectorYN и FaceRecognizerSF).
- PAM-интеграция: `pam_exec.so` с бинарным хэндлером `/usr/local/bin/bioauth-pam`.
- Модели: ONNX YuNet (детектор лиц 228 КБ) и SFace (вектор эмбеддинга 128-d, 37 МБ).
- Fallback: При любой ошибке или несовпадении лица возвращается код выхода != 0, передавая управление обычному вводу пароля PAM.

## Безопасность
- Никаких захардкоженных путей пользователя — автоопределение или чтение из `/etc/bioauth/bioauth.conf` и `~/.config/bioauth/`.
- Не сохранять сырые кадры лиц при повседневной аутентификации (только в RAM во время верификации).
- Никаких зависаний камеры: таймаут захвата кадра не более 1.5 секунд.
