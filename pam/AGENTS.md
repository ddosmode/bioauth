# AGENTS: Модуль pam/

## 1. ЦЕЛЬ
Реализовать безопасный шлюз между подсистемой PAM Linux и ядром биометрии.

## 2. ЧТО СДЕЛАТЬ
- Создать исполняемый скрипт/обертку `bioauth-pam`:
  - Читает переменные окружения PAM (`$PAM_USER`).
  - Определяет директорию эталонных векторов целевого пользователя (`~/.config/bioauth/enrollment/<user>.npy` или `/var/lib/bioauth/<user>.npy`).
  - Вызывает ядро верификации в silent/headless режиме с жестким таймаутом (2 секунды).
  - При успехе завершается с exit-кодом `0` (PAM_SUCCESS).
  - При несовпадении, таймауте или ошибке завершается с exit-кодом `1` (PAM_AUTH_ERR), что позволяет PAM бесшовно запросить ввод пароля.
- Создать шаблон конфигурации для `/etc/pam.d/sudo` и `/usr/share/pam-configs/bioauth`.

## 3. ГРАНИЦЫ
- Не перезаписывать напрямую `/etc/pam.d/*` без предварительного создания бэкапа `.bak`.
- Исключить любые интерактивные запросы (`read`, `input()`), так как PAM выполняется неинтерактивно.

## 4. ПРОВЕРКА
- Запуск `bioauth-pam` с симуляцией PAM: `PAM_USER=usernarne ./bioauth-pam`.
- Проверка кода возврата `$?`.

## 5. РЕЗУЛЬТАТ
Готовый к установке в систему скрипт `bioauth-pam` и конфигурационные файлы PAM.
